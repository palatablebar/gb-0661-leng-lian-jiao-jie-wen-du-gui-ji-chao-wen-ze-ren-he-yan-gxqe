# 数据定义

shipment 是字符串货运批号，前导零保留。probe 是校准档案键。at 必须含时区偏移，进入规则后转换为 UTC。value 使用 Decimal，哨兵 N/A、NULL、未知、空串和短横线均为缺失，不能变成零。unit 为 C/℃ 或 F/℉；华氏先转摄氏，再加校准偏移。

每个 shipment+UTC时刻构成业务键。同键相同温度保留最早来源行，其余隔离；同键温度矛盾时全部隔离，避免任意选一条。探头修正范围为−80到80°C。交接区间采用[start,end)，端点属于后任。责任重叠或缺边保留证据，不任意分配。

采样间隔超过15分钟时整段未知，短间隔按线性轨迹处理。高于8°C的分钟与超出8°C的温差积分均为 Decimal；阈值交点精确切分。未覆盖的首尾时段未知。超温分钟与热暴露分别用min及°C·min，输出六位小数。

空文件、仅表头、全空行分别为EMPTY_FILE、HEADER_ONLY、BLANK_ROWS。运行无采样也会显示未知覆盖，不把未知认作达标。行数不包含表头和重复分段表头。原始行号按CSV逻辑记录结束时的物理行号保存。
