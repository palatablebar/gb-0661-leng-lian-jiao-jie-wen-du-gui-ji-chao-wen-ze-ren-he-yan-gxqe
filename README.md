# 冷链交接温度轨迹与超温责任核验

面向冷链质控员的轨迹复核工具。七个业务模块：轨迹采信、探头校准、交接区间、超温积分、质量隔离、责任对账、批次复核。输入是带偏移时间的CSV采样、探头校准和交接区间；输出为责任方超温分钟、温差积分和逐行隔离证据。

核心计算将温度折线按8°C交点及交接端点切分，长缺测不插值，重复键冲突全部隔离。详细定义见 `docs/DATA-DICTIONARY.md`，规则与测试登记见 `docs/DEPTH.md`。

## 启动

```sh
docker compose up --build -d
```

访问 http://localhost:18200 ，初次启动自动导入配送脏样例。工具条可选择标准轨迹或旧设备编码后运行；轨迹采信页可粘贴自己的CSV与修改阈值。每个模块API可单独用内置样例试算，`GET /docs`查看请求结构。`POST /api/runs`持久化完整批次，输入摘要和参数一致时复用；隔离页可导出CSV。

```sh
docker compose config --quiet
docker compose exec -T app pytest -q
docker compose down
```

数据存于命名卷 records。停止和重新启动不丢失数据；需要清空全部本项目演示数据时，在确认无需保留后执行 `docker compose down -v`。

## 演示

1. 在超温积分页查看八批责任分段。
2. 进入交接区间核对09:30责任边界与未知段。
3. 进入质量隔离筛选CONFLICT并导出。
4. 选择标准轨迹运行，责任对账应四账相等。
5. 重跑同一样例不增加批次；批次复核使用当前版本确认，旧版请求返回409。

源码按 `app/modules/` 垂直切分。`sample_data/`含三份CSV及两份规则档案，`tests/`为模块与端到端测试。不接实时设备，不对未知温度补造数据。
